# Subnetting Calculator

A Python tool for calculating network details from CIDR notation.

## Features

- Network Address
- Broadcast Address
- First Host
- Last Host
- Host Capacity Calculation

## Technologies

- Python
- IP Addressing
- Networking Fundamentals
- Subnetting

## Example

Input:
192.168.1.0/24

Output:
Network Address: 192.168.1.0
Broadcast Address: 192.168.1.255
First Host: 192.168.1.1
Last Host: 192.168.1.254
